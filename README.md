# ClearView

가볍게 열고, 선명하게 감상하는 Windows 사진 뷰어. 고해상도 사진을 화면에 맞게 먼저 표시하고, 확대하면 보이는 영역을 원본에서 다시 읽습니다.

## 설치

Windows 10/11 x64와 .NET Framework 4.8이 필요합니다. 별도 브라우저 런타임이나 대형 이미지 라이브러리를 묶지 않습니다.

[GitHub Releases에서 설치 파일 받기](https://github.com/redpowerkk-cpu/ClearView/releases)

- 설치 파일: `artifacts/ClearView-Setup-0.1.0-x64.exe`
- 무설치 파일: `artifacts/ClearView-Portable-0.1.0-x64.zip`을 풀고 `ClearView.exe` 실행
- 설치 위치: `%LOCALAPPDATA%\Programs\ClearView`
- 시작 메뉴와 선택적 바탕 화면 바로가기. 관리자 권한이 필요하지 않으며 기본 파일 연결을 변경하지 않습니다.
- 제거: Windows 설치된 앱 목록 또는 설치 폴더의 `Uninstall.exe`

현재 0.1.0은 코드 서명되지 않은 첫 개발 버전입니다. 저장소에는 소스와 빌드 도구를 보관하고 생성한 실행 파일은 Git에 포함하지 않습니다.

## 주요 기능

- 사진 파일 열기, 폴더 탐색, 여러 파일 선택, 끌어놓기
- 파일명의 숫자를 고려한 자연스러운 정렬과 이전·다음 탐색
- 화면 맞춤, 원본 100%, 마우스 위치 중심 확대·축소와 드래그 이동
- EXIF 방향 반영, 보기 화면 회전, 내장 색 프로필의 sRGB 변환
- 전체화면과 자동으로 숨겨지는 조작부, 슬라이드쇼, 파일 정보와 파일 위치 열기
- 원본 사진은 읽기만 하며 회전·확대로 원본 파일을 수정하지 않습니다.

JPG/JPEG, PNG, BMP, TIFF, GIF, ICO 등 Windows WIC가 읽을 수 있는 이미지를 사용합니다. **GIF와 다중 페이지 TIFF는 첫 이미지만 표시합니다.** HEIC·WebP·AVIF·카메라 RAW는 설치된 Windows 코덱에 따라 지원 여부가 달라지며 별도의 전용 디코더는 포함하지 않습니다.

## 로딩과 메모리

1. 큰 사진은 작은 미리보기를 먼저 표시하고 화면 크기에 맞는 이미지로 교체합니다.
2. 현재 사진의 앞뒤 파일을 백그라운드에서 미리 읽습니다.
3. 캐시에 보관하는 이미지의 추정 픽셀 메모리를 128 MiB 이하로 유지하며 오래된 항목부터 비웁니다.
4. 확대할 때 전체 원본을 계속 보관하는 대신 보이는 영역을 잘라 필요한 해상도로 읽습니다.
5. 빠르게 사진을 넘기면 대기 중인 요청을 최신 요청으로 교체하고 이전 결과를 버립니다.

캐시 한도는 프로그램의 전체 메모리 한도가 아닙니다. 현재 표시 중인 이미지, 확대 영역, Windows 디코더의 임시 메모리, GPU와 런타임 메모리는 별도입니다. 디코더 내부에서 이미 진행 중인 작업을 강제로 취소하지는 않습니다. 특히 일부 형식은 작은 영역만 요청해도 전체 데이터를 읽을 수 있습니다.

실제 속도는 파일 형식, 압축 방식, 디스크, Windows 코덱과 하드웨어에 따라 달라집니다. 모든 고용량 사진에서 무지연을 보장하지 않으며, HDR·광색역 모니터의 정확한 색 재현을 측색 검증한 제품은 아닙니다. 측정 조건과 수치는 [PERFORMANCE.md](PERFORMANCE.md)에 있습니다.

## 단축키

| 키 | 기능 |
| --- | --- |
| Ctrl+O / Ctrl+Shift+O | 파일 / 폴더 열기 |
| ← / →, Page Up / Down | 이전 / 다음 사진 |
| Home / End | 처음 / 마지막 사진 |
| 휠, + / - | 확대 / 축소 |
| 0 / 1 | 화면 맞춤 / 원본 100% |
| R | 보기 화면 90도 회전 |
| F11, F, 두 번 클릭 | 전체화면 |
| Esc | 전체화면 해제 / 슬라이드쇼 중지 |
| Space | 3초 간격 슬라이드쇼 시작 / 중지 |

## 빌드와 검사

Windows PowerShell에서 실행합니다. Windows에 포함된 .NET Framework C# 컴파일러를 사용하며 추가 패키지 다운로드가 필요하지 않습니다.

```powershell
.\build.ps1
.\package.ps1
```

검사는 합성 이미지 파일 약 440 MB를 생성합니다. 사용자 사진을 읽거나 업로드하지 않습니다.

```powershell
.\tests\run.ps1 -Generate
# 화면 검사까지 실행하려면 (테스트 중 전체화면 전환):
.\tests\run.ps1 -Ui
```

결과는 `tests/output`에 저장되며 Git에서 제외됩니다. 회전, 확대 영역의 원본 픽셀 일치, 파일 잠금 해제, 캐시 퇴출, 연속 탐색, 손상 파일 복구 등을 확인합니다. UI 캡처는 앱 내부의 실제 렌더링을 저장한 것이며 바탕 화면 촬영은 아닙니다.

## 라이선스

ClearView 소스는 MIT 라이선스입니다. Windows와 .NET의 시스템 구성 요소는 해당 공급자의 라이선스를 따릅니다. 앱에는 광고, 계정, 원격 분석, 자동 업로드 기능이 없습니다.
